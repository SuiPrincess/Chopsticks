# マーケティング・グロース戦略メモ

## ポジショニング

「懐かしの指遊びが、eスポーツ級の見た目で帰ってきた」

- 誰でもルールを知っている（学習コストゼロ）×ネオンビジュアル＝SNS映え
- 1ゲーム1〜2分＝ショート動画と相性が良い
- 対面2人プレイ＝「その場で盛り上がる」動画が撮りやすい

## ASO（App Store最適化）

- タイトル: `Chopsticks - 割り箸バトル`（一般名詞「割り箸」で検索流入）
- キーワード候補: 割り箸 / 指遊び / チョップスティックス / 休み時間 /
  暇つぶし / 2人対戦 / オフラインゲーム / 頭脳ゲーム / マンカラ系
  （「マンカラ」で伸びた前例: シンプル伝統ゲーム×スマホの市場は実証済み）
- スクリーンショット構成案（6枚）:
  1. 対戦画面＋「あの指遊びがアプリに」
  2. ランク戦ラダー「CPU Lv.10を倒せるか？」
  3. 鬼難易度「勝てたら自慢していい」
  4. 特殊ルール一覧「毒・爆弾・ミラー」
  5. 2人対戦「1台で対面バトル」
  6. テーマ5種のカラバリ並べ

## バイラル施策（実装済みの仕掛け）

- リザルトのShareLink: 「CPU Lv.Xを撃破！」→ Xでのスコア自慢導線
- 「鬼に勝てたら自慢していい」はスクショ共有を誘発する文言設計
- 今日の挑戦: 全ユーザー同一ルール → 「今日の毒＋爆弾やばい」という会話が生まれる
- 連続日数・連勝: 習慣化とスクショの動機

## ショート動画ネタ（TikTok / YouTube Shorts / Reels）

1. 「小学校でやったアレ、ガチ勢いた」— 鬼AIにボコされる動画
2. 「爆弾ルールで4連鎖全滅」— 盤面が全部吹き飛ぶ瞬間
3. 「毒ルール、初手で終わるｗ」— 特殊ルールの理不尽さネタ
4. カップル/友達対戦のリアクション動画（対面モード）
5. 「AIのヒント通りに打ち続けたら勝てるのか」検証

## 収益モデル（実装済み）

| 導線 | 実装 |
|---|---|
| プレミアム¥480（買い切り） | テーマ5種＋ヒント無制限 |
| 投げ銭 ¥160/¥600 | おにぎり/お弁当 |
| ヒント1日3回制限 | 使い切り時にプレミアム案内 |
| メニューの王冠アイコン | 常設ショップ導線 |

方針: **ゲームプレイは完全無料**。Pay-to-winなし＝レビュー(星)を守る。
課金は「見た目」と「便利」だけ。子供も遊ぶゲームなので広告なしは差別化になる。

## リテンション・上達ループ（実装済み）

- 今日の挑戦（日替わり共通ルール・1日1回クリア記録）→ 通算7回で報酬テーマ「ミッドナイト」
- 今週の試練（週替わり・鬼＋特殊ルール3種・週1回クリア記録）→ ライト層は毎日、ガチ勢は毎週の2層ループ
- 難易度「鬼」撃破で報酬テーマ「オニ」→「勝てたら自慢していい」に見える報酬を接続
- 報酬テーマの進捗はショップ画面に常時表示 → ショップ訪問の動機とデイリーの動機を同時に作る
- 攻略ガイド: CPUに負けた直後のリザルトから開ける →「悔しい」を離脱でなく上達に変換
- リプレイ: 逆転の一手を見返す → スクショ/録画共有のネタ
- デイリーリマインダー（19:30・オプトイン）で連続日数の途切れを防止

## 申請前チェックリスト（App Store Connect）

1. IAP 3プロダクト作成（IDはapp-store.md）→ 審査に「App内課金」を含めて提出
2. Game Center: リーダーボード1件＋実績6件をASCで作成（IDはapp-store.md。未設定でも動作はする）
3. メタデータは日本語＋英語の2ロケール（本文はapp-store.mdに準備済み）
4. スクリーンショット5枚×2ロケール（構成案はapp-store.md）
5. プライバシー: データ収集なし（トラッキングなし・広告なし・解析なし）→「データは収集されません」
6. 通知の使用目的: デイリーリマインダー（オプトイン）を審査メモに記載
7. ローカルネットワーク使用: 近接対戦（NSLocalNetworkUsageDescription設定済み）を審査メモに記載
8. TestFlight: 課金サンドボックス（購入→復元→機種変相当）と近接対戦の実機2台確認
