# Chopsticks（割り箸バトル）

指遊び「割り箸（チョップスティックス）」のiOSアプリ。SwiftUI製。CPU対戦（ランク戦・デイリーチャレンジ・フリー対戦）、1台2人対戦、近くの人（Multipeer）・オンライン（Game Center）対戦に対応。

## 遊び方

- 各プレイヤーは手（デフォルト2本）を持ち、指1本ずつでスタート
- 自分の手を選んでから相手の手をタップすると、攻撃した手の指の本数が相手の手に加算される
- ちょうど5本になった手は死亡。全ての手が死んだプレイヤーの負け
- 相打ち（両者全滅）は、とどめを刺した手番側の勝ち
- 60ターンで決着しない場合はサドンデス判定（生きてる手の数 → 指の合計が少ない方 → 引き分け）
- 次の相手の攻撃で死にうる手は赤く光り、警告アイコンと破線の枠でも示す（色だけに頼らない）
- 初回起動時は遊び方（5ページ）を表示。メニューの「?」と設定からいつでも見られる

## ルールオプション

| ルール | 内容 |
|---|---|
| オーバーフロー | ON: 5を超えたら余りでループ、ちょうど5で死亡 ／ OFF: 5以上で即死亡（クラシック） |
| 分割 | 攻撃の代わりに自分の指を手の間で再分配。並べ替えだけの分割と、自分の生きている手を0本にする分割は不可 |
| 復活 | 分割で死亡した手に指を割り当てて復活できる |
| 手の数 | 2本／3本 |
| 毒 | 指1本の手で、指2本以上の相手の手を攻撃すると即死。ただし毒を使った手も死ぬ相討ち（開幕の1本同士は通常攻撃。全員1本で始まるため、開幕から相討ちしか選べないと後手必勝になる） |
| 爆弾 | ちょうど4本になった手は爆発して死に、他の全ての手に1ダメージ（連鎖あり）。分割パネルに事前警告あり |
| ミラー | 攻撃した本数が自分の手にも加算される |
| ダブルタップ | 1ターンに2回攻撃できる |

## 遊び続けたくなる仕掛け

- **🏆 ランク戦**: CPU Lv.1〜10の梯子。各レベルで必要な★（Lv.1〜3は1勝、4〜7は2勝、8〜10は3勝）を集めて昇格。負けると★が減り、同じレベルで負けが続くとCPUが少し手加減する。Lv.MAX後は「Lv.MAXでの勝利数」を積み上げる。標準ルール固定
- **🗓 今日のチャレンジ**: 日付から決まる特殊ルールとCPUレベル（誰が遊んでも同じ条件）。1日1回ボーナス+50XP。通知で知らせる
- **経験値・レベル・称号**: 全モードの勝敗・パーフェクト・大逆転などでXPを獲得。Lv.50まで、称号つき
- **実績**: 28種（隠し実績あり）。解除時にトースト表示、Game Centerにも送信
- **連続プレイ日数**: 今日遊ばないと途切れる状態をメニューに表示し、夜にリマインド通知
- **続きから**: CPU戦・2人対戦は中断しても保存され、メニューの「続きから遊ぶ」で再開（3日以内）
- **プロフィール**: レベル・戦績・最短勝利・実績一覧
- **演出**: 手が死ぬと画面シェイク＋「BREAK! / POISON! / BOOM!」バナー、紙吹雪、効果音（アセット不要の合成音）と触覚フィードバック
- **結果シェア**・**レビュー依頼**: ランク昇格や自己ベスト更新など「気分が良い出来事」の直後にだけ、バージョンごとに1回
- **通知**: 勝利を重ねたあとに一度だけ許可を尋ねる。設定でいつでもON/OFF
- **設定**: 効果音・振動・演出ひかえめ（視差効果の低減にも追従）・ニックネーム・戦績リセット

## 対人戦

- ホストがルールを決め、`gameStart` で盤面を配布。ゲストの画面でも自分の手が常に下側に表示される
- ゲスト側のハンドラ設定前に届いたメッセージは保持され、取りこぼさない
- リマッチは先手を交代。同時に申し込んでも1回だけ開始。断る・退出・切断・バックグラウンド移行は別々の文言で通知
- 通信は暗号化必須（MultipeerConnectivity）。Info.plistの`NSBonjourServices`は`_tcp`/`_udp`の配列で宣言

## CPU

- **かんたん**: ランダムに行動
- **つよい / ランク戦**: αβ枝刈り付きミニマックス探索（設定に応じて4〜6手読み）。60ターン判定も探索に含める。探索はバックグラウンドで実行し、画面は固まらない
- ランク戦: レベルが低いほどランダム行動が混ざり、浅く読む

## アーキテクチャ

```
Chopsticks/
├── App/            エントリポイント（起動準備・実績トースト・通知予約）
├── Models/         ゲームルール（純粋なロジック、UI非依存）
├── AI/             AIEngine（行動生成＋αβ探索）
├── Progression/    経験値・レベル・実績・デイリーチャレンジ・対戦結果
├── ViewModels/     GameViewModel（@Observable、手番進行・演出・対人戦の状態機械）
├── Networking/     Multipeer / Game Center と共通プロトコル
├── Views/          SwiftUI画面・コンポーネント・エフェクト
├── Utilities/      戦績・設定・保存・サウンド・触覚・通知
└── ChopsticksTests/ ユニットテスト
```

ルールの適用は `GameState.apply(_:)` に一元化されており、実プレイとAIのシミュレーションが必ず同じ挙動になる。

## ビルド

- Xcode 16 / iOS 17.0+（iPhone専用）
- `Chopsticks/Chopsticks.xcodeproj` を開いてビルド。プロジェクト定義は [XcodeGen](https://github.com/yonaskolb/XcodeGen)（`Chopsticks/project.yml`）で管理しており、ファイルを追加したら `cd Chopsticks && xcodegen` で再生成する
- Info.plist（Bonjour配列・ロック画面色・向き・起動設定）とプライバシーマニフェスト（`PrivacyInfo.xcprivacy`）、アイコン・アクセントカラー（`Assets.xcassets`）を含む

## テスト

`Cmd+U`（スキーム `Chopsticks` に `ChopsticksTests` を設定済み）。ルール・AI・戦績・実績・デイリー・保存・対人戦の同期（モック通信でホスト/ゲストの握手、再戦、同時リマッチ、切断、バックグラウンド）を検証する。

> テストは戦績・実績・保存データを初期化するため、実行するとシミュレータ上のアプリのデータも消える。
